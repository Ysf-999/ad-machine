# Shared Strategy Notes Template

Every saved creative pack (FB ads, LFS, UGC, native ads) must include a `## Strategy Notes` section after the variations and before the testing recommendation. This section proves the strategy without making the ad itself academic.

Use specific lever choices, not generic labels. "Cialdini Lever: similarity-matched social proof at CTA" beats "Cialdini Lever: social proof."

Lever options live in `references/cheatsheet.md` under "Lever Naming Convention." Use those short names.

## Template

```markdown
## Strategy Notes

**Awareness Stage:** [unaware | problem-aware | solution-aware | product-aware | most-aware - and why this length/directness fits]
**Market Sophistication:** [stage 1-5 - what the market has heard and why this angle is not stale]
**Buyer Belief Shift:** [current belief -> new belief]
**Market Signal:** [VOC / review / forum / competitor signal used, with source]
**Schwartz Lever:** [awareness stage / sophistication stage / mass desire / mechanism / belief chain / gradualization / identification / camouflage]
**Halbert Lever:** [starving crowd / list match / A-pile / AIDA / grabber / specificity / 25% close]
**Kennedy Lever:** [marketing triangle / differentiation triangle / lead gen / romancing / 11-part CTA / bundle]
**Cialdini Lever:** [reciprocity / commitment / social proof / liking / authority / scarcity / contrast / rejection-then-retreat]
**Wundt Inhibition:** [what hesitation the copy removes - pulled from Wundt excitation/inhibition lever]
**Copy-Chief Pass:** [what was sharpened before validation]
```

## Required Levers

- Schwartz, Halbert, Kennedy, Cialdini, Wundt - all 5 fields are required.
- Each lever must name a specific operating choice (not just the framework name).
- "Wundt Inhibition" should name the specific objection or doubt the copy neutralizes.

## Optional Add-Ons

- For UGC and AI talking-head scripts: add `**Reference Control Pattern(s):**` listing 1-3 selected pattern IDs from `references/control-library/index.md` with a one-line adaptation note for each.
- For long-form statics: add `**Belief Chain:**` listing the gradualization sequence (yes-train of small acceptances).
- For BOF ads: add `**Offer Math:**` (price anchor, bundle logic, guarantee positioning).
