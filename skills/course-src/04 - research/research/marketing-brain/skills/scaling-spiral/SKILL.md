# Scaling Spiral

## Purpose

Turn signal into spend. Once an archetype, angle, hook, or LFS works, expand it without losing the core belief shift that made it win.

Use the shared master references in `../../references/` for research/copy strategy: Schwartz for awareness/sophistication, Halbert for market hunger and central idea, Kennedy for offer/proof/CTA, Cialdini for contrast/social proof/authority/scarcity/commitment, and Wundt for frequency, fatigue, and retargeting paths.

If the user passes `--extreme`, make expansions more aggressive while preserving the winning mechanism: harder hooks, stronger enemy/failed-alternative contrast, bigger visual pattern interrupts, punchier CTAs, and more urgent retargeting inhibition removal. Rank scale potential first and leave final approval to the launch owner.

## Required Inputs

Prefer:
- winning asset or brief
- spend, CTR, CPC, CVR, CAC, ROAS/MER, AOV, hold rate, or other signal
- audience/channel
- comments/sentiment
- landing page and offer context
- `creative-ledger.csv` row and `performance-feedback.md` diagnosis

If metrics are unavailable, produce a hypothesis expansion plan and label it unvalidated.

Do not expand because a pre-launch score is high. A score can queue a test; only spend feedback can create a scaling spiral.

## Expansion Layers

1. Same angle, new visual format.
2. Same belief shift, new hook.
3. Same archetype, new objection.
4. Same mechanism, new proof.
5. Same winner converted into native image prompt batches using `$native-image-prompt-gen`.
6. Same winner converted to AI talking head.
7. Same winner converted to creator brief.
8. Retargeting variants that remove remaining inhibition.

## Output Format

Return:
- why it likely won
- what must not change
- which metric proved the win and which failure modes were ruled out
- 20 horizontal static variations
- native image prompt concepts for the strongest variations
- 5 AI talking-head scripts
- 5 creator-video briefs
- retargeting angles
- test matrix
- kill/scale criteria

## Metrics Starter

If the user has no KPI rules, start with directional signals:
- CTR/thumbstop for hook strength
- CPC/CPM for market resonance
- CVR/CAC for belief and offer fit
- comments for objection discovery
- hold rate for video pacing

## Operator Rule

Do not "iterate" by making random new ads. Preserve the winning psychological mechanism and vary one meaningful dimension at a time.
