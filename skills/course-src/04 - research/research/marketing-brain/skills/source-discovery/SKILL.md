# Source Discovery

## Standard

Find sources where buyers reveal actual demand, not polished brand language. Respect platform rules: use public pages, approved APIs, user-provided exports, or manual browsing. Do not bypass logins, paywalls, rate limits, or access controls.

Use `../../references/boron-letters-halbert-dtc-framework.md` for starving-crowd logic: prioritize sources that prove recent buyer hunger, repeated advertiser activity, high intent, repeat buying, or active category comparison.

Use `../../references/influence-dtc-dr-breakdown.md` when source choice should uncover persuasion triggers: visible authority cues, scarcity pressure, social proof density, commitment rituals, reciprocity offers, liking/identity signals, and price/value contrast.

Use `../../references/avatar-research-dtc-playbook.md` for Decision-First source planning: choose sources based on the decision being made, not because they are easy to scrape. Define what evidence would change the ad angle, archetype, objection stack, LP section, or test plan before collecting data.

## Source Types

Prioritize by product:
- Reddit threads and subreddit search
- TikTok comments and creator videos
- YouTube comments
- Amazon, Shopify, Trustpilot, App Store, or niche review sites
- Meta Ad Library and competitor landing pages
- forums, Discord exports supplied by the user, Facebook group exports supplied by the user
- search autosuggest, People Also Ask, niche blogs

## Credibility Score

Score 1-5:
- relevance to the exact problem
- buyer intent or purchase context
- emotional specificity
- objection/failure detail
- recency
- engagement depth
- source diversity
- evidence that the person is a real user or prospect
- trigger-event visibility
- behavioral evidence, not only stated opinion

## Output Format

Return a source map:
- source name
- URL/search query
- why it matters
- decision it can inform
- expected insight type
- credibility score
- behavioral / attitudinal / classification value
- extraction notes

## Query Generation

Generate queries around:
- problem phrases
- failed alternatives
- "is it worth it", "does it work", "side effects", "before after"
- competitor names
- identity phrases
- desired outcome
- complaints and refund language

Do not over-index on one platform. If Reddit is thin, pivot to reviews, forums, comments, and competitor ads.

## Internet Avatar Source Rule

Prioritize sources that show what people actually did: bought, compared, searched, tried, abandoned, complained, refunded, or recommended. Use opinions as copy language, but use behavior to judge market reality.
