# A06 — 6 action item ugc ad (Video Ads Mastery)

**Assignment briefing, not an edit demo: three Milanote briefs (two creator-led UGC ads and one AI-voiceover, Dr. Squatch-style ad) that each ask for 3 hooks + 1 hold = 3 ads, with no example edits given on purpose.**

## Key lessons

1. **Build every ad as hooks plus one shared hold.** Each brief is "3 hooks, 1 hold, 3 total ads". Each variation puts a different hook on the identical hold. [00:00-03:00, 03:00-06:00]
2. **Hold = a numbered story script laid out in order.** In UGC #1 the hold is 8 talking-head clips, with arrows showing the order. Cut out the bad takes and trim the footage to the script. [00:00-03:00]
3. **A true UGC concept pairs matching footage.** The same creator delivers the script to camera and also films b-roll of herself using the product. The talking-head and b-roll footage should match. [00:00-03:00]
4. **UGC #1 (Salon Quality Hair, hair dryer): vary only the hook.** Everything after the hook is identical across the 3 ads. Talking points are salon quality at home, and other dryers burn your hair while this one doesn't. [00:00-06:00]
5. **UGC #2 (Kids Getting Sick): the creator delivers only one hook line, so vary the hook visual instead of the hook text.** Three hook visuals:
   - the creator talking
   - the creator picking up the package or unboxing
   - the product missing, "or something else"
   
   [03:00-06:00]
6. **UGC #3 (Shady Shilajit) is not true UGC.** It has no user-generated content. It uses an AI voiceover instead of an on-camera creator, and still counts loosely as UGC. The 3 VO hooks each go onto the single VO hold. [03:00-09:00]
7. **For #3, edit like Dr. Squatch.** Go "as crazy as possible": lots of b-roll, quick and punchy. Put something new on screen about every 2 seconds. Visualize the script tactically and keep it "very engaging, very eye catching". [03:00-09:00]
8. **Workflow for #3:**
   - Lay the VO mp3 down as the base track.
   - Pile b-roll on top and animate things.
   - Visualize what the script says.
   - Show the lab results from the brand's website, for example as a screen recording. The concept is a mini VSL: the only shilajit brand that posts third-party lab results. [06:00-09:00]
9. **Don't use all the footage.** The brief links about 20 Google Drive folders. Pick the best clips from the variety, use as much as possible to stay engaging, and invent creative hooks from the content. [06:00-09:00]
10. **Research before editing.** Look at UGC ads on Atria, and study Dr. Squatch ads there. Clients like editors who can do this style. [03:00-09:00]
11. **Do the assignment, then compare.** Edit first. Then take the hooks, retention and live UGC breakdown modules, come back to compare and improve, and send each finished ad in for feedback. [00:00-09:00]

## Editing recipe
No edit is shown. The implied process:

**UGC #1 and #2 (creator footage)**
1. Pick the best takes and cut out the bad ones.
2. Trim the clips to the numbered script and assemble the hold in order (8 clips in #1, 9 in #2).
3. Cut in the creator's matching b-roll (product use, close-ups) over the hold.
4. Build 3 hooks:
   - #1: 3 different spoken hooks.
   - #2: 3 different hook visuals for the one line.
5. Export 3 ads, each as one hook plus the same hold.

**UGC #3 (AI VO)**
1. Place the VO mp3 for Hook 1/2/3 followed by Hold1 as the base track.
2. Cover it with b-roll that changes about every 2 seconds, visualizing each script line.
3. Animate elements.
4. Include a screen recording of the website lab results.
5. Export 3 ads.

## How an ffmpeg/Python agent applies this
1. **Hooks + shared hold = 3 ads (lessons 1, 4).** AUTOMATE. Render each hook clip, concatenate it with the same hold using the ffmpeg concat demuxer or filter, and loop over the hooks in Python. Re-encode to a uniform fps, resolution and audio rate first so the concat is clean.
2. **Hold ordered by script, bad takes removed (2).** JUDGE for take selection. A model should transcribe (e.g. Whisper), match takes to numbered script lines and flag flubs or repeats. AUTOMATE the trim and assembly with `-ss/-to` cuts from the chosen in/out points.
3. **Matching creator b-roll (3).** JUDGE. Check by frame sampling that b-roll shows the same creator and product, then AUTOMATE the overlay or cutaway at the script lines where the product is mentioned.
4. **UGC #2 hook visuals (5).** AUTOMATE the three variants as different first clips (talking, unboxing, product missing) over the same line of audio. JUDGE which clips actually show those actions.
5. **AI-VO base track (6, 8).** AUTOMATE. Use the provided mp3s, or generate TTS, as the audio bed. Build the timeline from VO word timestamps (forced alignment), place b-roll segments per script phrase, and mix with `amix` or `-map`.
6. **New visual about every 2 seconds (7).** AUTOMATE. Compute the VO duration, divide it into segments of about 2 s on phrase boundaries, and assign a clip to each. Add light zoom or animation with `zoompan` or `scale/crop` expressions. JUDGE whether each clip visualizes its line, using a vision model on sampled frames.
7. **Lab results screen recording (8).** AUTOMATE if a recording is supplied: overlay or cut it in at the lab-testing lines. Generating the recording itself would need a headless browser capture (e.g. Playwright video), which is a possibility rather than something the lesson says.
8. **Captions in the Dr. Squatch style.** AUTOMATE. Burn ASS captions in bold white sans-serif with a black outline (Outline and BorderStyle) at top or middle alignment. The exact size is not specified, so choose and tune it.
9. **Choose the best clips from about 20 folders (9).** JUDGE, with a vision model scoring variety and quality. AUTOMATE the download and scene detection (e.g. PySceneDetect) as preprocessing.
10. **Research on Atria (10).** SKIP. It is a web tool and needs human or browser access. Reference ads can be analyzed if provided.
11. **Feedback loop, other modules (11).** SKIP. Course-process advice; the agent only needs to export all 3 ads.
12. **Output sizes.** AUTOMATE exports at the sizes listed in the brief (1080x1080, 1080x1350, 1080x1920, 1920x1080) with `scale`/`pad`/`crop`. Which sizes are required is unclear, so check the brief.
