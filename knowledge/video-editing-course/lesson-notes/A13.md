# A13 — 13 asset management (Video Ads Mastery)

**Download all client footage to a local SSD and keep one fixed folder structure per client (UGC Content, Product Shots, High-Production Videos, Ad Concepts). Knowing your library makes you faster, gives you ad ideas and makes you an asset to the team.**

## Key lessons

1. **Store all client footage locally on an SSD, not in the client's Google Drive or Dropbox.** If your computer lacks space, buy an SSD. [00:00]
2. **Two benefits: speed and familiarity.** You never dig through the client's Drive or Dropbox when you start an ad. Knowing what footage exists tells you what you can do, and "some of the best ideas for the ads come from knowing the content." [00:00]
3. **Use one master folder, "Clients" (the SSD), with one folder per client (Client A, B, C...).** Everything for one client and brand lives in one place. [00:00]
4. **Give every client folder the same four subfolders.** [00:00]
   - **UGC Content:** creators, testimonials, reviews, "basically people".
   - **Product Shots:** B-roll of the product in use or in action.
   - **High-Production Videos:** only if the brand has any.
   - **Ad Concepts:** all exported ads for that client.
5. **Add files whenever the client sends content or you find it, for example on their Instagram.** [00:00]
6. **Download new content the moment you see it.** Do not leave it as a link in Slack or Discord. The instructor has forgotten client-sent content that way. Seeing it later while browsing folders prompts "this is new, we should use this." [03:00]
7. **Sub-organise inside UGC Content by creator.** Example: a "Sarah" folder for a creator who records for the brand every month. Ads from a specific creator can perform better, so you will want to reuse that creator's content. [03:00]
8. **For visual products (his example is a skincare cream), keep a "hooks" folder of scroll-stopping, interesting visuals.** [03:00]
9. **Keep the structure clean.** It saves time when making ads, and a tidy library lets you tell quickly in a team brainstorm whether you already have content for an idea. The sentence is cut off at 05:55. [03:00]
10. **Know the content well enough to propose pairings, e.g. "we have this clip and this clip, and they pair with this".** This is very valuable to a client and team, and it should be you because you make the ads. [06:00]
11. **At minimum, have an organization system and organize content by brand.** No tool is prescribed. [06:00]

## Editing recipe

This is not an edit walkthrough. The setup workflow for a new client is:
1. Create the client folder under "Clients" on the SSD.
2. Create the four subfolders: UGC Content, Product Shots, High-Production Videos (if applicable), Ad Concepts.
3. Download all existing client footage and sort it into those folders.
4. Inside UGC Content, add a subfolder per creator. Add a "hooks" folder for visual products.
5. Whenever new content arrives (Slack, Discord, Instagram), download and file it immediately.
6. Export finished ads into Ad Concepts.

## How an ffmpeg/Python agent applies this

1. **Local storage on SSD (lesson 1): AUTOMATE.** Work from a local root directory (e.g. `Clients/`). Use `shutil`/`rclone`/API downloads to pull client footage locally before editing. Check free disk space with `shutil.disk_usage` and warn if low.
2. **Speed and familiarity (lesson 2): AUTOMATE/JUDGE.** Build and cache a manifest per client (path, duration, resolution, creator, tags via `ffprobe`). JUDGE: use a vision model on sampled frames to describe clips so the agent "knows the content" and can draw ad ideas from it.
3. **Master folder with per-client folders (lesson 3): AUTOMATE.** `os.makedirs` for `Clients/<client>/`.
4. **Four fixed subfolders (lesson 4): AUTOMATE.** Create `UGC Content`, `Product Shots`, `High-Production Videos` (only if the brand has any) and `Ad Concepts`. Write exports to `Ad Concepts`. JUDGE: classifying an incoming file as UGC, product shot or high-production needs a model or human look at it.
5. **Add files as they arrive (lesson 5): AUTOMATE.** An ingest function takes a URL or file, downloads it and files it into the right client folder. Instagram sourcing needs permitted access and is optional.
6. **Download immediately instead of leaving links (lesson 6): AUTOMATE.** Scan incoming messages or links, download them at once and log them in the manifest. SKIP if the agent has no Slack/Discord access.
7. **Per-creator subfolders (lesson 7): AUTOMATE/JUDGE.** Create `UGC Content/<creator>/` when the creator name is known from metadata or filename. JUDGE: identifying the creator from the video when no name is given. Track per-creator ad performance only if the data is supplied.
8. **Hooks folder (lesson 8): JUDGE.** A model rates clips for scroll-stopping visuals. AUTOMATE copying or linking the selected clips into `hooks/`.
9. **Clean structure (lesson 9): AUTOMATE.** Enforce naming conventions, lint for stray files outside the fixed structure, and keep a searchable index.
10. **Propose pairings (lesson 10): JUDGE.** Use the manifest and clip descriptions to suggest which clips pair for a given concept. A human or model should check that the combinations fit.
11. **Organize by brand at minimum (lesson 11): AUTOMATE.** Brand-level folders are the baseline, with the rest of the structure layered on top.
