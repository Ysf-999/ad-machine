## What is taught
How the editor styles VSL-ad captions in Premiere Pro: centre them on screen, set a bold sans font at about 80 pt, and stack two soft drop shadows for readability. He then says to proofread the auto-transcribed captions and delete duplicates. He also checks that black screens carry no stray text. The final layer is sound effects, and he recommends building a personal SFX library from the effects you download on each ad.

## Concrete rules and numbers
- Select all captions, open Properties, and click the centre cell of the Zone grid to put every caption at screen centre. This overrides the default of captions sitting at the bottom.
- Font: Proxima Nova Bold. Size: "something around 80".
- Fill is white. Stroke is off (unchecked).
- Shadow 1 (soft readability glow):
  - Distance 0, so the shadow sits directly behind the text. The angle doesn't matter at distance 0.
  - Size is a "relatively high value" (the screen shows about 165).
  - Blur is increased (the screen shows about 14.2) to give a "soft smooth shadow right behind the text".
  - Opacity is lowered so it isn't too strong (the screen shows about 71–74%).
- Shadow 2 (optional, added with the plus button):
  - Set to black, distance 0.
  - Size increased a little, blur "not so much".
  - Screen values: opacity about 57%, angle 135°, blur about 8.8, size about 70. At first the default was opacity 100, angle 135°, size about 40.
- Shadow parameters, as he explains them:
  - Distance is how far the shadow sits from the text.
  - Angle is the direction the shadow is cast.
  - Size is how big the shadow is.
  - Blur softens it.
- Check the caption script for transcription errors, since the software makes mistakes. Delete duplicate captions where two overlap.
- Make sure black-screen sections are clear and no other text overlays them. Remove any leftover text.
- Sound effects are the last layer. Build your own SFX library from the effects you use repeatedly, adding to it as you download effects for each ad.
