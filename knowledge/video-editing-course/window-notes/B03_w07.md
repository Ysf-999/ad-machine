## Concrete rules and numbers
- Make one sequence per hook version (h1, h2, h3). Start with h1. Each sequence is a plain, normal sequence named after the hook.
- Import the voiceover folder, which holds the files generated with ElevenLabs. For the h1 sequence, drop in "h1 hook dogs" VO first, then "hold dogs" (the body) and the CTA.
- Shortcuts:
  - **D**: delete the selected empty gap or clip. Used to remove silent gaps between VO segments.
  - **C**: razor tool. Used to cut the VO into segments.
  - **A**: track select forward. Selects everything to the right of the click, so the whole right side can be moved after a cut or gap change.
  - **Shift+A**: track select backward. Selects everything to the left.
- The first thing to check on the VO is its loudness (how loud it sounds). He uses the audio level meter panel, which shows the sound level.
- Project file details visible on screen:

  - VO file durations:

    - h1 hook dogs: about 2:05
    - h2 hook dogs: about 1:14
