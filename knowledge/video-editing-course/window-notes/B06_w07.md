## What is taught
This stretch finishes the A-roll/VO audio chain in Premiere Pro for a postpartum UGC ad. The chain is a Multiband Compressor with the "Broadcast" preset for crisp, podcast-like voice. Gain is then set so the voice doesn't peak above -6 dB, and a Hard Limiter with the "Limit to -6dB" preset catches any peaks. If the limiter makes the audio harsh, the multiband compressor's gain is lowered so the voice isn't pinned at -6 all the time. At the end he moves on to the next layer, music, which he calls the soul of the video that can make or break the ad.

## Concrete rules and numbers
- On the Multiband Compressor, open the preset list and choose **Broadcast**. It gives a podcast-style, crisp voice. Many other presets exist, but Broadcast is the one he mostly uses.
- Compare with and without the effect by toggling it. The effect was clearly better on the line "Can we stop with the getting my body back narrative…".
- Adjust gain so the voice isn't peaking above -6 dB.
- Add **Hard Limiter** (Amplitude and Compression → Hard Limiter) and apply the preset **"Limit to -6dB"**.
  - Anything that would peak above -6 dB (e.g. -3 or -2) is cut off at -6.
  - Limiter panel values on screen: Maximum Amplitude -6.0 dB, Input Boost 3.0 dB, Look-Ahead Time 7 ms, Release Time 100 ms, Link Channels checked, Peak mode selected.
- Side effect: hard limiting can make the audio sound harsh. The fix is to lower the multiband compressor's **output gain** so the signal no longer sits at -6 all the time and moves naturally.
  - The track meter after the fix reads about -6.0 (the output gain knob shows -6.00).
  - Multiband output gain was set to about -6 dB (screen reads "Gain: -6 dB" in the later frame).
- Recommended stack: **Multiband Compressor then Hard Limiter**, on the track's effect slots.
- Settings vary with the recorded audio, so experiment to fit each recording.
