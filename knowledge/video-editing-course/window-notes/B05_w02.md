## What is taught
How to source a stock/UGC b-roll clip for an organic-style ad: search TikTok for a keyword, pick a clip that matches the script beat, download it in HD, and drop it into the Premiere timeline. The editor trims it to the part that carries the message, then moves on to the next script note. The beat here is "dramatic drag clip" for the line about the dog pulling and dragging the owner down the street.

## Concrete rules and numbers
- Search TikTok with a plain keyword that matches the script (here "dog pulling"). Nothing fancy is needed.
- Pick a clip where the dog pulls hard. Prefer natural motion blur from camera movement and a POV shot, which the instructor calls "really, really good for us".
- Download via tiktokdownloader.io. Paste the video link and choose "Download MP4 HD". Higher-quality footage is worth using when available.
- Save into the project's "stock" folder and name the file simply (here "dog pulling.mp4"). The downloaded file was about 3.6 MB.
- Trim the clip to the part that delivers the most message. Here that is roughly the first 2 seconds. The order is: first the owner's hand showing the struggle, then the dog straining and bending against the lead.
- If the clip is low quality, use Properties and "Fill again" (probably Set to Frame Size/Scale to Fill; the transcript is garbled) so it fills the vertical frame.
- Work through the script's colored notes in order. After the drag clip, the next note is "back clip closeup / red arrow to it - to highlight it".
- The ad script's matching line is "…lets them drag you down the street." Its note is "dramatic drag clip".
