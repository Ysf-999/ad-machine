## Concrete rules and numbers
- Technical requirements in the brief: video resolution and aspect ratio. The "Sizes needed" card lists 1080x1080 (1x1), 1080x1350 (4x5), 1080x1920 (9x16) and 1920x1080 (16x9). Only 1080x1920 (9x16) appears checked.
- Ad structure for a UGC ad: 3 hooks + 1 hold. "Variations needed" reads 3 hooks, 3 total ads.
- Hooks in this brief are copy only, with no script or voiceover. The editor must use the hook copy at the start of the hold, so each ad = hook-copy text on screen + the shared hold VO.
- Download all content from a creator, including previous batches. Reuse their old b-roll so you have more material. "Running out of b-roll is your worst nightmare."
- Folder template (numbered, in this order):
  - `_Export`: final videos about to be submitted.
  - `01 Project Files`: Premiere, After Effects and Photoshop files for the batch, plus MS Paint outputs.
  - `02 Footages`: whatever the client provides (studio shots, influencer shots, etc.).
  - `03 Assets`: anything downloaded from the internet, with subfolders `_Client` (logos, end cards, brand assets), then audio, image and video.
  - `04 Other`.
- Naming template: "Client - Batch# - Concept Name - Format - Type - Editor - Variation#". The same name is used for the .prproj and .aep files.
