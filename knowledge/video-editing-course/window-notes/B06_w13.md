## What is taught
Two points. First, captions don't have to be 100% polished. A deliberate mistake, such as a caption changing out of sync with the cut, can add UGC authenticity if it stays clear and fits the audience and concept. Second, after captions are done, the editor adds hook text. Because Windows emojis look bad, he builds the hook text as TikTok-style rounded text boxes in Figma, exports each as a PNG, and places it in the project's assets folder. Edits are made by changing the text in Figma and re-exporting over the same file.

## Concrete rules and numbers
- Normal practice is to keep the cut and the caption change on the same line, so the caption changes at the moment the clip changes.
- Authenticity trick: let the next caption appear slightly after the cut, or while she isn't speaking, so caption timing is a little off. He calls it a "deliberate mistake".
- The mistake only works "as long as it's clear". Edit for the audience and the concept.
- Order of work: captions first, then hook text from the script.
- Hook text is a PNG image, not a native text layer. The reason is emoji quality: Windows emojis are poor and Apple emojis are not available to him.
- Figma workflow:
  - One page per client.
  - A large batch number heading, with everything related to that batch to its right.
  - A reusable "TikTok organic text" template (from a Figma community file) is copied to the top of each new page.
  - Variants are white box with black text and red box with white text. They come as One Liner, Two Liners and Three Liners frames.
  - Font shown: Proxima Nova.
- Figma frame settings visible:
  - Auto layout, hugging the text.
  - Padding 40 horizontal and 20 vertical.
  - Gap 10.
  - Corner radius about 20–22.
  - Fill #FFFFFF with black text.
  - Export at 1x PNG.
  - Example frame size is about 1162×177, growing to about 1401×177 when text is added.
- Select the frame (the one-line text container) so it exports as a group, not the text alone.
- Save exports to the project folder `03 Assets / Image`. Files are named HOOK 1.png, HOOK 2.png, HOOK 3.png, plus Prolactin img.png and SAFEZONES.png.
- To change copy (his example: a "Postpartum" line), edit the text in Figma, export again, and replace the file. He keeps these separate from client-supplied assets because he created them.
