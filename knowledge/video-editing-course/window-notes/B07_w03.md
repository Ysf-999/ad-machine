## What is taught
How to calibrate and prompt AI voiceover in ElevenLabs Studio so the generated read sounds natural and credits aren't wasted. The instructor sets the voice settings once up front, then uses two script-level tricks: CAPITALIZING words for emphasis and inserting dashes for pauses. He also switches the generate mode so only a selection is generated.

## Concrete rules and numbers
- Voice settings (hover each for an explanation): Voice, Alias, Volume, Speed, Stability, Similarity, Style Exaggeration, Speaker boost. Set them before any generation and keep them fixed.
- Changing the voice settings mid-generation cancels everything generated so far and wastes credits.
- The generate button defaults to "playing until end", which generates the whole script. If the script isn't ready, that wastes credits. Switch it to "generate selection" while testing individual lines.
- Capitalize a word to stress it (example: "3 reasons I REGRET getting this for my dog"). It gives a lot of emphasis on that word.
  - He didn't like how the capitalized version sounded and went back to the original (lowercase) take. His point is to compare both and choose.
  - Use the version history/chapter ("OG" vs "NEW") rather than regenerating.
- A dash/minus symbol ("-") in a sentence creates a pause.
  - It sometimes works and sometimes doesn't, so regenerate if it doesn't.
  - Without it, there is sometimes no gap in the audio, and fixing that manually in the edit is annoying.
- Workflow before generating everything:
  1. Go through the whole script.
  2. Capitalize the words that need it.
  3. Add dashes where needed.
  4. Set the mode back to "playing until end".
  5. Generate.
