## What is taught
The instructor builds an AI voiceover for "Hook 1" of the Honeypacks ad in ElevenLabs Studio. He copies the hook script from the ad's ideation board, assigns a custom voice, and cleans the script. He then generates once with default settings to hear the baseline, and tweaks voice settings (mainly Style Exaggeration set to 15%) before regenerating.

## Concrete rules and numbers
- Workflow: create a Studio project named after the ad (here "Honeypacks - Slipping HP in Drinks"), create a chapter named "Hook 1", paste the Hook 1 AI VO script, choose the voice, then generate.
- Choose the voice first, before generating. The voice panel showed the default "Carepod Mama" and the instructor switched to the custom "Honey Packs Female Test".
- ElevenLabs sometimes fails to find a custom voice. The fix was refreshing the page a couple of times.
- Clean up the script before generating:
  - Fix punctuation, e.g. "I have a confession - I was bored of the same old with my man...."
  - Merge the lines "So, I slipped some of this into my man's drink last night...And let's just say...I'll NEVER underestimate him again." into one paragraph.
  - Add emphasis with capitals on "THIS" and "NEVER".
  - Use ellipses for pauses.
- Read the script aloud yourself before generating. The team does this to get a feel for how it should sound.
- First generation uses no changed parameters, to hear the default output. The instructor's verdict was "not bad". Original defaults on screen:
  - Stability: about 50–55% (slider slightly right of centre)
  - Similarity: about 75–80%
  - Style Exaggeration: 0 (None)
  - Speaker boost: on
- Planned change, "not too drastic": lower Stability slightly (slider moved a little left of centre), lower Similarity a bit (slider moved to about 70%), and set Style Exaggeration to 15% ("Yeah, let's do 15").
- Script edit: change "my man's drink" to "his drink" ("I slipped some of this into his drink last night"). Reason: "my man" is already said earlier in the same sentence, so the repetition is unnecessary. The 38:45 frame still shows "my man's drink" in the text, so the edit may not have been applied yet.
- Changing voice settings on a paragraph affects every paragraph using that voice. The UI warned "This change will affect 2 paragraphs (in 1 chapter) that will need to be regenerated." After saving, press Regenerate.
- The generated clip was about 6 seconds long (player showed 0:06).
