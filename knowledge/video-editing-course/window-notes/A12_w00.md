This window covers the first technique, stacking "open loops". Each new reveal raises a question the viewer's brain needs answered, so the viewer keeps watching. ## Concrete rules and numbers
- Open a loop in the first few seconds. In the Mr. Beast example the main hook is "Will he survive 50 hours buried alive?"
- Layer more loops on top of the first. Each new problem or reveal creates another question the viewer needs closed. Mr. Beast's layers were a storm and a possible coffin flood, dropping oxygen levels, and the support team considering pulling him out.
- In ads, do the same thing "just faster". Each new reveal should not just add information. It should raise a new question.
- Example four-loop stack for a weight-loss supplement ad:
  1. Show someone who lost 50 pounds. This opens "how did they do it?"
  2. Show them eating a box of pizza while looking skinny or fit. This opens "they can eat that and still look like that?"
  3. Show a before/after photo where the "before" is only 90 days old. This opens "how did such a dramatic change happen so fast?"
  4. Show testimonials of others getting the same results. This opens "does this work for everyone, not just this one person?"
- The principle holds whether the video is 3 seconds, 3 minutes or 30 minutes long.
