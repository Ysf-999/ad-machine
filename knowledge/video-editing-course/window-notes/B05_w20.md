## Concrete rules and numbers
- Text layout: put the text in the centre in two lines instead of one long line that runs off the screen. He says the "layout works better" because the brain absorbs it faster.
- Reading rationale: while the viewer consciously reads the first 2–3 words, the brain has already skimmed the last symbol (the full stop). This is claimed to help the viewer read and absorb faster.
- Caption scope: skip the hook text (captions 1–2) and the CTA line ("Shop the sale with CTA"). Captions should cover only the body of the video.
- After generating captions, select all the caption clips and click "Upgrade Caption to Graphic" in the Graphics/Properties panel. Captions then become editable graphic layers on the V4 track.
- Hook text creation:
  - Use the Type tool (T) and type the hook: "This 1 change stops pulling forever".
  - Font: HeadingNow, "65 Norm Medium", chosen because the hook is a title. The default Lucida Console, size 100, is replaced.
  - Size: font size is 64 before the change. The Properties panel shows 50 after centre alignment.
  - Alignment: centre-aligned, wrapping to two lines.
- Hook styling:
  - He prefers a background colour box over a shadow or other effects to make the text pop.
  - Background: white, with the text fill set to black.
  - Background opacity is 100 (slider on screen).
  - The second slider ("expansion") is set to 18.6 in the frame, though he says "opacity is 10, I don't know what is that just expansion something". Treat his spoken value as unclear.
  - Roundness is about 21 (the on-screen slider was 0 at the last frame and is being dragged).
  - Stroke and shadow are off.
- He sets these by instinct, not from tested settings.
