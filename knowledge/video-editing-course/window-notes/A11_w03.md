## What is taught
The instructor ends the hooks section by saying a hook should be understood in half a second. He then moves to systematic ad testing. You never run a single version of an ad. You test messaging and visuals separately, so a winner can be traced to one variable.

## Concrete rules and numbers
- Hook readability test: if someone can understand the hook in half a second, it is done right. Keep what makes people interested, but make it quick and easy to read.
- Never run just one version of an ad. This differs from Instagram or YouTube content, where you upload one video and let it run.
- Two main test variables are messaging and visuals. Test them separately and almost never both at once.
- Messaging test (scenario one):
  - Use the exact same video and make 3 variations that differ only in hook text.
  - Each variation targets a different desire.
  - Weight-loss examples: "I lost 30 pounds without giving up carbs" (food freedom), "Finally hit into my old jeans" (specific goals), "No more hiding in photos" (emotional transformation).
- Visual test (scenario two):
  - Keep the messaging identical and change only the visual hook, again with 3 variations.
  - V1 opens with a before/after transformation.
  - V2 shows someone struggling, such as buttoning jeans.
  - V3 shows someone confident and happy, "rocking their results".
- Reason for separation: if variation 2 wins and both variables changed, you can't tell whether the message or the visual did it. "If you're testing both at once, you're just guessing."
- Use the result for future decisions. Example: if before/after wins, viewers respond to seeing results at the start, so open future ads with results.
